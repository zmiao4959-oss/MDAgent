# MiniClaw 自我进化平台化加固任务书

## 目标

在阶段 1–20 基础上完成三项工程化改造：

1. 拆分 `webchat.py` 和 `app.js`，控制核心文件复杂度增长。
2. 实现正式的自动源代码补丁编排器，使批准后的提案能够生成真实候选。
3. 将经验、源代码提案、Skill 草案和可执行策略纳入统一治理、备份、恢复和清理。

开发过程由 Codex 按固定测试门禁自动验收；产品运行时仍保留功能开关和精确确认，不扩大源码写入权限。

## 总体约束

- 保持现有 API 路径和前端用户行为兼容。
- 每个阶段新增独立验收脚本和自动化测试。
- 每个阶段创建独立 Git 提交。
- 不允许补丁模型修改评估器、治理器、Git 晋升逻辑或已有测试。
- 自动生成候选不等于自动合并；晋升仍要求 `PROMOTE <experiment_id>`。
- 治理恢复必须验证路径和校验和，并在覆盖前生成安全备份。

## 阶段 21：WebChat 与前端模块拆分

### 实施

- 将 `/api/evolution/*` 路由从 `webchat.py` 提取到独立路由注册模块。
- 通过小型上下文对象注入项目解析、工作区和配置，避免路由模块依赖整个 Adapter。
- 将经验面板和反思面板逻辑从 `app.js` 提取到 ES module。
- 前端模块使用依赖注入获取当前项目和 DOM 节点，不创建新的全局可变状态。
- 保留所有现有路径、请求体、响应体和事件绑定。

### 验收

- `webchat.py` 不再直接定义 evolution 路由。
- `app.js` 不再包含经验反馈、回滚和反思请求实现。
- 路由清单与拆分前一致。
- 新模块可通过 Node 语法检查。
- 现有 WebChat、设置和进化测试全部通过。

### Git 节点

`阶段21：拆分WebChat进化路由与前端模块`

## 阶段 22：自动源代码补丁编排器

### 实施

- 新增异步 `LLMSourcePatchAgent`，通过现有 LLM Router 生成结构化 JSON 修改计划。
- 测试阶段仅允许创建 `tests/test_evolution_generated_*.py`。
- 实现阶段只允许精确文本替换或受限新文件创建，不接受 shell、任意脚本或自由路径。
- 新增异步单候选运行流程，严格保持“旧实现上测试失败后才请求实现补丁”。
- 向 LLM 提供脱敏提案、受限源码上下文和生成的回归测试，不提供密钥、Git 元数据或仓库外文件。
- 增加 `EvolutionService.run_automated_source_experiment()`。
- 增加受开关保护的运行 API，要求提案已批准且精确输入 `RUN <proposal_id>`。
- 自动运行只产生 `patched` 候选；评估、提交和晋升继续由后续固定门禁负责。

### 配置

- `source_auto_patch_enabled: false`
- `source_context_max_files`
- `source_context_max_chars`
- `source_llm_timeout_sec`

### 验收

- 假 LLM 可完成“生成失败测试 → 修改实现 → 测试通过”。
- LLM 在复现测试真正失败前不会收到实现补丁请求。
- 非 JSON、路径逃逸、已有测试修改、模糊替换和危险内容全部拒绝。
- 未启用、未批准或确认口令错误时不能启动。
- 主工作区保持干净且源码不变。

### Git 节点

`阶段22：接入受限LLM源代码补丁编排器`

## 阶段 23：统一进化治理与生命周期

### 实施

- 统一列出所有受管进化资产及其大小、类型和状态。
- 导出中加入源代码提案、实验和受管文件清单。
- 备份覆盖：经验数据库、Trace、审计、源代码进化数据库、Skill 草案和可执行策略。
- 不备份 Git worktree 内容和用户手工安装的普通 Skill；候选源码由 Git 提交恢复。
- 恢复时验证 ZIP 路径、manifest、SHA-256 和数据库结构。
- 目录恢复采用临时目录和可恢复替换，覆盖前自动生成安全备份。
- 增加 dry-run 清理报告；实际清理要求精确确认。
- 清理范围限定为过期 Skill 草案、过期可执行策略草案和已结束源代码实验的可安全移除 worktree。
- 所有治理动作写入审计日志。

### 验收

- 完整备份和恢复可以还原源代码提案数据库、Skill 草案和可执行策略。
- 篡改文件或路径穿越的备份会被拒绝。
- dry-run 不修改任何文件。
- 错误确认不能清理；正确确认只删除报告中的受管目标。
- 不删除已批准策略、已安装 Skill、活动实验和仓库外内容。

### Git 节点

`阶段23：统一进化资产治理备份与清理`
