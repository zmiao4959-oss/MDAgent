# 任务协商提示词试验（2026-10-25）

本轮只调整角色提示词及画布注入的通信提示，不新增工具、协商参数、调度状态机或执行层拦截。沿用现有 delegate/continue 和 message_agent。

## 约定

1. coordinator 首次发出【任务协商】，说明拟做工作、真实输入、用户约束及产物，本轮不执行业务。
2. 专业角色给出【能力反馈】：能做、不能做或需纠正、缺少输入、建议范围。尽量四项短答，不提前展开技术方案。少量只读核查允许；没有 list 的角色可仅用 execute 列目录，不能借此探测版本、启动模拟或生成文件。
3. coordinator 采纳有依据的修正，通过原 task_id 的 continue_task 发【确认执行】，而非创建新任务。
4. 画布沿双向 message_agent 连线交换相同消息，每次发出后结束当前激活。提示中明确哪些接收者可直接回信；缺反向连线时报告缺口。完成后可发送一次【执行结果】，不循环确认结果。
5. 同范围纠错、补交、状态查询不重做协商；新增业务或明显扩展范围才协商新增部分。直接用户任务不额外要求用户确认。已有 request_skill/publish_skill 及自动恢复流程按原请求契约执行，不插入新的协商轮次。

咨询任务显示 done 只表示能力反馈完成，不表示模型、输入文件或模拟已完成。协商不能扩大用户授权，也不能改变角色已有工具与职责。

## 测试方法

- 使用当前配置的 deepseek-flash，温度 0.1，加载实际角色 SYSTEM.md、工具定义及画布通信提示。
- 测试器记录模型输出和工具调用意图；不调用 tool_registry.execute。模拟目录查询、任务回执和提交结果均为测试夹具。最终轮次允许只读读取本地 Skill 文档；不运行命令、不创建业务产物、不启动 GPU 计算，不写入用户的项目会话。
- 专业角色咨询、新派单漏标咨询、确认后提交、用户直接请求、普通 coordinator 首次咨询及沿原任务确认、画布发起/反馈/确认、单向连线缺口，共 14 个场景。
- 自动检查只检查协商行为（是否先反馈、是否选择正确通信入口、是否沿原任务确认、确认后是否选择 run_gpumd 等），并人工阅读关键反馈。不是完整生产 Agent loop 的端到端测试。
- 回归：`python -m pytest tests/test_agent_prompt.py tests/test_subagent_continue.py tests/test_agent_graph.py -q`，32 项通过。
- 最终 14 个协商行为场景均完成检查：12 个来自最终整轮、2 个来自修正只读命令分类和目录夹具后的定向补测。汇总 JSON 的 `case_sources` 保留各样本来源，未覆盖早期原始输出。

## 迭代记录

- 初轮测试把所有 execute 都视作业务执行，提前终止了只读目录核查；这属于评测分类过严，不能据此认定发生了模拟或文件写入。
- 修订评测器，仅把狭窄识别的目录查询/echo 视作只读，其余 execute 仍作为业务调用意图记录。此分类器只用于评测，不是安全策略或 Shell 沙箱。
- 后续补测还遇到 `if exist ... echo`、stderr 重定向、只读 find/head 等目录核对写法；确认均无业务副作用后补充分型，并让目录夹具返回明确的合成文件清单，避免空泛的工具占位说明诱发重复查目录。
- 画布原提示只列出可发送对象，未提供接收者能否回信的信息；补充直接回信节点列表，并明确无回信节点时报告连线缺口。
- 复核输出时，能力反馈仍曾展开未经查证的具体语法与参数。进一步要求咨询聚焦能力和前提，具体技术方案留到确认后依据资料核实。
- 原始输出保留在同目录的 JSON 中；最终结果见 [最终模型输出](task-negotiation-2026-10-25-final.json)。

## 使用与限制

重启 MiniClaw 后用新会话观察真实任务，避免旧会话已直接派单的上下文影响试验。普通模式关注同一 task_id 是否先反馈再确认；画布需保留可往返的直接连线，并预留咨询和确认消息预算。单节点直接用户任务不需要自我协商。

这是提示词层的软约定。小样本检查通过不等于始终遵守，能力反馈本身也可能出错。GPUMD 命令、元素映射、物理参数及最终产物的正确性不在本次协商行为检查的通过范围内，仍需原有专业资料核实与运行验收。

实际样本中，仍有反馈偏长、提前提及未经核实语法或元素顺序的情况。不能把本报告的协商行为通过率当作专业回答准确率；后续真实任务应同时观察这一点。

复现命令（会使用已配置的模型 API，工具不会被实际派发）：

```powershell
python scripts/eval_task_negotiation.py --live --output docs/evaluations/task-negotiation-recheck.json
```
