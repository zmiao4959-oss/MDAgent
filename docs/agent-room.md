# 公共频道协作

MiniClaw 的 WebChat 现在支持三种项目协作方式：默认委派、智能体画布和公共频道。底层共用 Agent、Profile、会话、工具登记、安全检查与运行轨迹。

## 使用

1. 重启 MiniClaw，打开一个项目。
2. 点击聊天区上方的「协作方式」，选择「公共频道」。
3. 选择成员，用「↑」「↓」调整调度顺序，设置同时工作人数、公开发言上限、成员工作轮次与整轮超时，点击「保存并应用」。成员顺序会随会话保存，重新打开设置后仍然保留；运行期间不能调整。
4. 回到项目对话发送任务。用户消息投递给所有成员；成员公开发言广播给其他全部成员。
5. 打开「协作方式」查看公开记录和当前运行状态。切换模式前暂停当前任务；原画布、频道配置分别保留。

## 发言和静默

`publish_message(message)` 使用现有 `tool_registry` 登记。模型只填写消息，运行时通过受控 `_context` 传递已绑定房间和成员的回调。模型不能选择或覆盖发言身份。工具仅在公共频道成员的请求中开放；默认模式和画布模式看不到、也不能执行它。

角色原有业务工具和 Skill 白名单继续生效。频道模式屏蔽旧的委派与外部通信工具。新增的通信能力不会授予额外的文件、命令或模拟权限。

成员可以读取资料、检查文件、使用已有工具后决定是否公开发言。普通结束文本、工具观察和内部过程保存在该成员的私有会话；没有调用 `publish_message` 就是静默，不需要特殊符号或空模型回复。

## 调度和预算

- 每个成员有独立收件箱和会话；同一成员顺序处理，不同成员可并行。
- 工作期间收到的新消息排队；下次激活合并连续未读消息。每轮使用固定输入快照。
- 公开消息拥有持久化递增序号、作者、消息 ID 和触发消息引用。发送者不被自己的消息再次唤醒。
- 新广播可立即唤醒空闲成员，无需等待发送者结束自己的工具循环。
- 运行时从用户排列的首个成员开始，按该顺序轮转分配空闲执行位置，跳过正在工作或没有未读消息的成员，实际遵守频道的并发配置。顺序影响启动处理的先后，不保证完成或发言的先后；仅调整顺序不会重置频道历史。
- 默认允许 24 条 Agent 发言、100 次成员激活、4 名成员同时工作、600 秒整轮运行。用户起始消息不消耗发言额度。
- 一次成功广播只消耗一条发言额度。静默也消耗一次成员激活；每次激活内部还受原有工具轮次限制。
- 发言额度耗尽后拒绝新发言，继续处理已接受消息。激活额度耗尽时完成已启动轮次；暂停或超时则取消成员。运行结束清空未处理队列，并记录未处理消息数量。
- `idle` 表示频道暂时空闲，不代表研究任务完成。通过公共频道执行计划任务时，不自动将计划项标记完成，也不自动重试失败的频道运行。

## 模式、记录和恢复

`CollaborationRuntime` 按根会话的 `metadata.collaboration_mode` 路由到默认 Agent、画布运行时或 `RoomRuntime`。旧会话没有该字段时，仍按有无 `agent_graph` 配置选择画布或默认模式。

配置与最近一次运行保存到根会话；每个成员的会话命名空间包含项目会话、频道编号与成员集合。同一频道后续用户轮次保留私有历史；不同项目隔离，更换成员集合会使用新的私有会话空间。单纯调整预算不会重置历史。

频道最近 200 条完整公开消息与递增计数持久化；项目对话另存各轮公开结果。刷新页面可恢复公开记录。进程重启会将上次运行中的记录标记为中断，不重放旧收件箱或自动续跑工具。

模式和配置在聊天请求接受、计划任务排队时取得快照。任务运行或排队期间，配置 API 拒绝切换；停止后可切回默认或画布。

## 第一版边界

- 入口为 WebChat 项目；Gateway、Telegram、Heartbeat 和 Cron 继续使用原入口。
- 公共频道暂不叠加计划模式；用户仍可在频道里讨论计划，也可执行已有计划项。
- 自动临时 Skill 的申请/构建/发布流程仍属于画布；已经按项目挂载且满足权限的 Skill 可沿用。
- 公共频道不提供共享文件版本锁或任务认领协议。成员仍在同一项目工作区，任务应明确产物分工；已有模拟服务的资源队列仍生效。
- 这是一种通信和调度机制。真实科研任务的产物质量、自由协商是否有效，仍需结合证据与运行结果评价。

## 代码与验证

- `miniclaw/tools/room_tool.py`：登记的公开发言工具。
- `miniclaw/runtime/room_context.py`：本轮通信能力、工具可见性和执行权限。
- `miniclaw/agents/room_runtime.py`：成员收件箱、并发调度、持久化记录和取消。
- `miniclaw/agents/collaboration.py`：三模式分发与配置快照。
- `miniclaw/channels/web/collaboration_routes.py`：模式配置和记录查询。
- `miniclaw/channels/web/static/collaboration.js`：配置界面与公开记录。
- `miniclaw/agents/room.py`：保留学习原型接口，发言已改为登记工具通路。
