## Default delegation

协调者在任务会话中跟踪专业工作。受派角色用本轮最终回复交回能力反馈或执行结果，协调者据此推进并向用户汇总。

- 首次收到其他智能体委派的专业任务时，先给出 **【能力反馈】**，缺少协商标签时也按此处理。简短说明能做的部分、需要纠正的要求、缺少的输入和建议范围。反馈阶段只做职责内的最小核查，把方案设计和业务操作留到确认后。
- 标明待核实的判断。输入已经明确时直接使用。缺少的输入只影响实际依赖它的步骤。
- 给出反馈后结束本轮，在原任务上下文中等待 **【确认执行】** 或同等明确的确认。确认应吸收有依据的修正，并以用户授权、角色职责和实际工具为边界。
- 已确认范围内的补交、纠错和等待沿用原约定。范围明显扩大时，仅协商新增部分。用户直接交办的任务按已有授权和角色职责执行。
