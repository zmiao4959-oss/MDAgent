# 参数决策表 · 首轮必须读

本页规则 D-01～D-08 是**设计政策**，给出探索起点及边界，不是两套势已验证的材料常数。

| 组 | 直接决定规则 | 缺参时的处理 |
| --- | --- | --- |
| 势/成分 | 保留用户文件；核对元素和版本 | 读决策包；不覆盖元素为 BLOCK，不猜配比 |
| 初态/尺寸/边界 | 已有模型优先，保留历史与取向 | 读文件/上游记录；没有模型时由势决策包给 CAND 建模需求 |
| 温度/压力 | 用户值锁定，显式转换单位 | 研究状态未定时给带假设的 300 K、0 GPa 常温基线；需要相变温区时读体系分支 |
| 数值参数 | 同任务文献优先，否则 D-01 | 输出数值与物理时间；标 CAND，不全留“待定” |
| 阶段预算 | 用户时长优先；否则 D-02 | 给初始和最大步数；不承诺 GPU 墙钟时间 |
| 输出 | 从所需时间/应变/温度分辨率反推 | D-03；正式与 trial 隔离，记录阶段映射 |
| 拉伸 | 单轴/双轴、应变定义、速率、终点闭合 | 拉伸页；运行时 L0 不阻断设计 |
| 结论与分析 | 区分数据生成、数值检查、科学结论 | 给已支持指标；未支持的完整判据标缺口 |

## D-01 · 通用数值候选

适用：无表面/真空、三向周期、轴对齐正交 bulk，使用本库两套势的常规有限温度探索。极高温/高压、近重叠、冲击或三斜变形需另评估。

- `dt = 1 fs`：CAND；GPUMD 默认/现有示例与 Pd 常规验证可作起点；不能称为 UNEP 任意任务已验证值。
- `npt_scr`：CAND；生产采样优先使用具相应涨落采样依据的选项。保留用户指定的其他算法并说明差异。
- `tau_T = 100 fs`、`tau_P = 1000 fs`；输入为 `tau/dt`。1 fs 时为 100/1000；0.5 fs 时为 200/2000。这是保留物理时间的政策，不是永远锁死输入比值。
- 正交独立压控的三个控制模量先用 `100 GPa`：CAND，来自现有示例的粗略控制尺度，不是测得的弹性常数；明显振荡或不同条件需重新评估。
- 普通 bulk 固定温压采用三轴独立控制；有指定对称性/盒型或剪切需求时单独选择。拉伸按专页划分驱动与未驱动轴。

依据：[C-01](../evidence/C-01-gpumd55.md)、[M-02](../evidence/M-02-barostat.md)、[现有 NPT 示例](C:/Users/35059/.miniclaw/workspace/skills/gpumd-script/examples/npt-relaxation/example.md)。

## D-02 · 有限预算

无用户时长时：固定状态先 `100 ps` 预平衡＋`100 ps` 生产，1 fs 对应各 100000 步。只允许一次 `100 ps` 延长预平衡候选，总计最多 300 ps；仍不满足本次健康筛查则报告状态，不能无限续跑。

预设随机种子 `20261020`，重复对照用 `20261021`，均标 CAND。已有速度/制备状态先保留；只有请求新初始化或有明确制备目的才重新分配速度。生成器独立短试跑的约 200 步只查流程，不当作物理预平衡。

## D-03 · 输出起点

固定状态/温度平台：thermo 每 `100` 步、轨迹每 `1000` 步、阶段末 restart（1 fs 时 0.1 ps/1 ps）；关键快速事件按专页缩短。每段重新声明非传播输出；提供阶段 ID、步长、起始时间、实际首个输出步及间隔，不能假设帧 0 就是 t=0。

PTM cutoff 首轮 `0.1`（CAND/当前工具默认），固定模板与口径；不为得到相变反复调阈值。报告均值时指定区间，RDF 原生是逐帧总 RDF。

## D-04 · 明确的健康筛查候选

固定平台末两个相邻 `20 ps` 窗口：T 均值偏目标不超过 `max(5 K, 2%T)`，压力均值偏目标不超过 `max(0.1 GPa, 2%|P|)`，两窗口体积均值相对差不超过 `0.5%`、每原子势能均值差不超过 `0.005 eV`。这些是工程筛查政策，不是平衡/遍历性证明；临界过程要保留转变段。

仅在已有统计能计算相应量时评估。当前 thermo 温压窗口统计、置信区间没有确认的专用工具，记为 `CHECK_PENDING`，不让 LLM 扫表算均值或谎报通过。U/V 的已有区间摘要可按实际工具使用。检查待执行不阻断候选输入的准备。

## D-05～D-08 · 对照、冲突与交接

- D-05：必要的步长敏感性初筛可安排相同物理时长 `10 ps` 的 1/0.5 fs 对照；保持 tau 物理时间。比较统计而非逐原子轨迹重合。是否必须做、接受精度和额外预算在方案内明示。
- D-06：研究结论敏感时，预先选择一次尺寸或速率/种子对照；不要把所有对照变成每次任务的强制全套计算。
- D-07：若用户同时给应变、速率、时长/步数，先验算；超出一步取整误差的矛盾标 NEEDS_DECISION，不能暗改硬条件。
- D-08：交接必须可区分“参数设计完成”“等待上游资产”“待执行检查”“最终判据缺工具”。对完整目标有工具缺口时，仍交付已支持的数据方案。
