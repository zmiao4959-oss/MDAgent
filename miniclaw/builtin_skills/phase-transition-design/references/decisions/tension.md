# 拉伸诱导结构变化的参数决策

先读[参数决策表](parameter-table.md)及势决策包。范围：三向周期、轴对齐正交 bulk 的盒子拉伸；表面、三斜剪切或其他载荷需要重新论证。

## T-01 · 先分清物理约束

拉伸是非平衡驱动路径。加载轴由 deform 的盒长增量控制，未加载轴按要求控压或固定长度；不能声称加载轴同时保持零压力。用户要求恒温恒压预平衡后拉伸时，分成两个阶段。

GPUMD 5.5 使用 `ensemble npt_scr` 独立方向压力参数与 `deform` 联用，语义按启用方向区分；输入行出现三个零压力数字，不代表拉伸轴实际应力也为零。[C-02](../evidence/C-02-deformation.md)

| 横向条件 | 决策 |
| --- | --- |
| 用户指定零横压 | 非加载轴目标 P=0 GPa；允许横向盒长响应 |
| 用户指定固定横向尺寸 | 保持未加载方向盒长；按 5.5 规则关闭其压控（控制模量 >2000 GPa）；报告约束变化 |
| 未指定 | 提出零横压 bulk 的 CAND 假设，不称为用户要求 |
| 同一加载轴要求规定长度路径又要求独立定压 | 标 NEEDS_DECISION，说明两者不能同时作为独立硬条件 |

## T-02 · 应变、速率和时间必须闭合

默认提出**工程应变**候选并明确标记；用户明确真应变则保留。

`εeng = (L−L0)/L0`；恒工程应变率时 `t = εmax/εdot`，`N = ceil(t/(dt×10^-15))`，每轴 `dLi = εmax×Li0/N`（Å/步）。`L0` 是正式预平衡末态 restart 中同一盒子的实际长度。

恒真应变率要求 `L(t)=L0 exp(εdot_true t)`；单一恒定 dL/步不会保持真应变率。不要把真应变 0.1 当作工程 10%，也不要静默用现有恒增量 helper 代替。完整指数路径未建立现成 helper 时，标出实现缺口，方案可先明确公式与需求。

用户给步数/速率/终点时按 D-07 验算。两轴相同工程应变必须分别乘各自 Li0，不可把同一个 Å/步复制给不同初长。

## T-03 · 首轮候选与来源

通用数值控制采用 D-01。已有模型和速度优先保留；通常先 100 ps 目标温度、三轴目标外压预平衡＋按原任务必要性检查，正式参考产生后进入加载。用户已交付合格预平衡态时，直接使用其参考，不强制重复。

UNEP 常规初筛可提出 `εdot_eng=10^8 s^-1`、上限 `εeng=0.10`（若用户未给）。这是采用官方 deform 例子的速率尺度形成的 CAND 起点，非材料推荐定律。Pd 玻璃优先读自身文献力学参照；不能拿冷却速率当拉伸速率。

必要时预先安排一次 0.5× 或 2× 速率对照，说明新增步数；不把一次速率结果推广到准静态实验。

## T-04 · 输出按应变分辨率决定

建议首轮 thermo 的工程应变间隔 ≤`10^-5`，轨迹 ≤`10^-4`（CAND）。恒工程率时：`interval = max(1, floor(Δε/(εdot×dt×10^-15)))`；可再设 thermo ≤100 步、轨迹 ≤1000 步的时间上限，取更小者。若一步本身超过分辨率，则明确冲突并减 dt 或调整所需分辨率，不能假装满足。

报告实际输出 Δε 与时间。1 fs、10^8 s^-1 时 100/1000 步分别为 10^-5/10^-4，应变 0.1 需 1 ns/1000000 步。

保留 thermo 的压力张量、U/K 与盒矢量，轨迹及正式参考；记录阶段偏移与首个实际输出步。采用拉伸为正的约定时 `σzz=-Pzz`（对压缩为正的压力），单位 GPa。它是当前体积下的应力口径；工程应力需按初始/当前截面关系另定义，不能直接改列名。

当前没有确认的应力–应变联合转换、转变应变定位、剪切带或局部塑性专用工具；原始数据可保存，最终判据的缺口单列。普通 MSD 还包含仿射拉伸，不能直接当扩散。

## T-05 · 参考绑定与现有 helper

已有 `tension_workflow.py create/prepare-load` 仅支持 `--axes x`、`xy`；三向周期正交盒。正式参考未产生时交付模板与 RUNTIME 依赖，不能问用户未来 L0、用初始盒长或 trial restart 顶替。

GPUMD deform 本身支持 z。**z 任务不能调用 `--axes z` 到当前 helper，也不能擅自改成 x**。generator 可依据 C-02 编写相应输入；运行时参考代入需已有支持的计算入口或明确的实现交接，不能声称现成 helper 已覆盖。x/xy 直接沿用已验证的两阶段入口。[C-02](../evidence/C-02-deformation.md)

## 交接完成条件

列出每轴驱动/约束、ε定义、速率/终点、dt、tau、时长/步数、参考来源、dLi 公式或值、输出实际分辨率、预平衡与有限验证；未知参考属于 RUNTIME_PENDING。只有材料目标或硬约束冲突才 NEEDS_DECISION，不把参考尚未生成误判成设计失败。
