## 现有依据

目标是金属玻璃制备或玻璃转变时，优先阅读[专题指南](../../topics/pdcunip-glass.md)。目标是晶化、元素偏聚或液–液转变时，需另找直接证据和判据，不能从文件名称推导这些能力。

## 本地数据提供什么

训练和测试文件均在本地，已逐帧读取并保存[统计审计](dataset-audit.md)。可以确认构型数、元素、原子数和保存的参考标签；没有逐帧温度、压力、生成路径标签，不能由这些文件单独还原全部制备条件。

现有数据可作为后续误差评估的输入资产。首版未运行模型预测，未验证数据集划分的独立性，也未建立每种成分的误差结论。

## 与当前工具的衔接

已有势能、体积、总 RDF、MSD 和 PTM 工具可以交付相应曲线及摘要。Tg 自动拟合、元素对分 RDF、化学有序和 Voronoi 指标尚未有对应专用工具。[能力清单](../../common/capabilities.md)

设计方案必须把“能生成研究数据”和“能完成最终判据”分别说明。资料给出了某种方法，也仍要检查当前运行系统是否能完成它。
