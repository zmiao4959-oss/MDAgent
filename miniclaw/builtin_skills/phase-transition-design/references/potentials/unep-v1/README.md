## 怎样使用研究证据

[U-02 文献卡](../../evidence/U-02-paper-scope.md)保存原论文的训练范围与化学有序研究方法。选定一个具体合金后，应进一步查其候选结构、成分、初态、物理条件和研究方法在原文中的对应位置。

本地已拥有主模型和八个集合成员；它们不等于八次独立的实验验证。若以后使用集合分歧作为风险信号，需要定义预测量、计算方法和校准依据。当前没有为此建立执行工具。

## 对 NPT 相变任务的初始判断

| 任务 | 本知识库建议的处理 |
| --- | --- |
| 元素全部被当前文件覆盖，观察有限时间内的结构演化 | 继续匹配相应文献，并使用结构演化专题设计探索 |
| 目标包含未覆盖元素 | 停止将本文件用于该模型，不通过改写元素名称绕过 |
| 目标是化学有序或元素分配 | 先核对采样方法和分析指标；查 MC/MD 与现有工具差异 |
| 目标是平衡相界或相图 | 明确需要的方法与精度，不能由一次 NPT 标签曲线直接交付 |
| 目标温区、压力或成分没有直接证据 | 列为待验证条件，说明探索范围和能够给出的结论 |
