# 专题 B · Pd–Cu–Ni–P 玻璃制备与转变

[总目录](../index.md) · [势函数档案](../potentials/pdcunip/README.md)

状态：有文献参照的设计建议，尚未本地复现。先读[P-02](../evidence/P-02-paper-protocols.md)区分原论文的常规验证、Tg 计算和小体系结构验证。

完整候选路径、阶段数值、快慢预算和输出频率现在见[Pd 决策包](../decisions/pdcunip.md)。本页主要解释研究背景，不再作为逐项留空的交接入口。

## 本专题的目标

围绕给定原子成分和制备历史，设计热路径，采集势能、体积、温度和所选结构指标，评估该路径下的玻璃转变信号。若目标只是某一 NPT 状态的结构比例，按实际范围完成，不自动扩展为 Tg 研究。

## 1. 成分与初态

优先从与原论文有直接对应的成分建立首个案例，具体成分及文献结果见[P-02](../evidence/P-02-paper-protocols.md)。相近成分另建记录；有限原子数的整数计数应与目标原子分数一起报告。

记录起始构型如何生成，是否已经经过熔化、保温、冷却或退火。若用户提供现成玻璃，保存其制备历史；未知历史会限制解释，不能自行补填。

## 2. 参数依据表应如何填写

| 项目 | 采用依据或当前状态 |
| --- | --- |
| 势身份 | [P-01](../evidence/P-01-local-model.md) 的本地文件与校验值 |
| 外压、边界、步长的文献参照 | P-02 常规验证条件；是否适用于本任务需要说明 |
| 起始温度与液态制备 | 需要核对同一计算目的的完整文献路径与实际初态 |
| 冷却路径与速率 | P-02 的 Tg 参照可作为候选，标注文献对象与适用差异 |
| 温控、压控、耦合与盒型 | 本知识库尚未核实该文献的全部细节；按方法依据提出并验证 |
| Tg 判据与拟合 | 记录能量–温度判据；拟合细节与工具尚待补齐 |
| 采样与重复 | 根据目标精度、时间尺度与预算预先安排 |

不把 AIMD 的步长抄到经典 NEP 任务，也不把小体系结构验证的时间直接当成大体系玻璃制备要求。

## 3. 先计算资源需求

固定步长下，路径时间由温度跨度和冷却速率决定，步数由路径时间除以 Δt 得到。使用文献速率时应先完成这个换算，再决定预算内的研究范围。[NPT 参数](../common/npt-parameters.md)

文献结构验证中 NEP 单温点 `2000000 × 1 fs = 2 ns`。这个数是该分支的时间换算，不证明其他成分或大体系经过 2 ns 就达到所需状态。

## 4. 数据与判据的最小交接

保留连续路径的能量、温度、压力与盒子信息，以及用于所选结构分析的轨迹。分阶段数据需要明确映射；只给一个末态模型不足以确定 Tg。

当前工具可以生成势能、体积、逐帧总 RDF、MSD、PTM 曲线及基本摘要。它们分别提供部分证据；平均 RDF、元素对分 RDF、Voronoi 有序和 Tg 拟合等与论文比较的需求，需逐项核对[执行能力](../common/capabilities.md)。

## 5. 当前可以和暂时不能交付什么

可以准备有依据的候选方案、运行既有受支持阶段，并交付实际计算的指标与局限。若要正式估计 Tg，需要明确拟合方法、窗口、温度对应和必要不确定度；当前没有专用拟合工具时，不让 LLM 目测或手算给出“精确 Tg”。

结构主要被分为 Other 不能单独证明玻璃，也不能直接给出玻璃转变温度。比较论文图线时，先核对是否为相同的成分、速率、制备历史、统计和结构定义。

## 下一份已验证案例需要保存的东西

实际势哈希、完整输入与模型身份、运行 ID 和状态、阶段路径、分析参数、原始输出、摘要、采用的拟合结果及其来源、与文献的差异。没有实际执行的数据保持为空，使用[研究方案模板](../templates/research-plan.md)记录待验证事项。
