## 状态含义

| 标签 | 含义 |
| --- | --- |
| 本地核实 | 读取文件或执行确定性统计得到的事实；不能自动证明科学正确性 |
| 论文报告 | 作者在文献指定体系与条件下报告的事实或结果；本项目未复现 |
| 方法依据 | 软件约定或通用方法资料，使用时仍需匹配条件 |
| 设计建议 | 本样稿提出的安排或推断，尚未成为已验证案例 |
| 待补充 | 未获得、未核对或当前资料无法确定的信息 |

每张卡保留对象、依据、定位和允许使用的结论。缺失字段明确写明，不补造。其他页面引用卡片，材料特定的定量结果集中保存在这里。

## 冲突处理

先检查是否使用同一势文件、成分、结构、外压、路径和分析定义。不同条件的结果并存，不能直接合并成一个“推荐值”。同条件资料仍冲突时保留两条出处，说明当前无法确定的部分。更正时记录受影响的证据卡和专题。
