| 项目 | 约定与定位 |
| --- | --- |
| time_step | 单位 fs；固定步长与最大单步位移两种设置；Caveats 说明默认值和跨 run 传播 |
| ensemble | 温度 K、压力 GPa；耦合参数 τ/Δt；弹性参数 GPa；Units and suggested parameters |
| 参数参考 | 温控约 100、压控约 1000 是官方参考；不是针对本任务的物理验证 |
| 盒子 | ensemble_standard 的三类压力控制分别对盒型与边界有要求；倾斜自由度不由等比例缩放提供 |
| dump_exyz | interval 是步数；has_potential 额外开启逐原子势能；设置不跨 run 传播，文件追加 |
| thermo.out | T、动能 K、势能 U、六个压力分量、九个盒矢量分量；不是逐行显式时间列 |

`thermo.out` 的 PIMD 说明不用于本知识库的经典 MD 方案。时间映射依赖步长、输出间隔和阶段信息；不能看到一个帧号就自动认作 MD 步数或温度。

## 对研究设计的意义

数值相同的耦合输入在不同步长下可能对应不同物理弛豫时间。盒型、输出与传播规则需要写入阶段计划。若要从 thermo.out 计算焓或其他派生量，需核对能量、体积、压力定义和单位，并检查现有工具是否提供该计算。
