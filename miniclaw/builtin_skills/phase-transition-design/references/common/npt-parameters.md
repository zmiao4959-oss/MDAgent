## 参数决策表

| 参数 | 选择依据 | 需要交付的说明 |
| --- | --- | --- |
| 温度与外压 | 目标问题、实验/DFT/本势的相关证据 | 目标值和路径来自哪里，哪些范围尚待验证 |
| 时间步长 Δt | 原子运动尺度、势与条件；文献参考后做所需数值验证 | fs；是否固定步长，验证过什么 |
| 温控/压控算法 | 需要的统计性质、体系和软件能力 | 算法名称、版本、适用理由 |

| 盒子自由度 | 候选结构变化、边界和施加的应力约束 | 等比例、正交独立变化或允许倾斜的选择 |
| 尺寸与初态 | 目标空间尺度、周期边界、缺陷与制备历史 | 原子数、盒子、种子、已计划的尺寸检查 |
| 弛豫/采样/重复 | 观测量的变化时间和统计需求 | 各阶段物理时间、区间、重复安排与预算 |
| 输出间隔 | 目标事件与后处理需要 | MD 步数、物理时间、字段、阶段标记 |

## GPUMD 5.5 的明确约定

`time_step` 的单位是 fs；`ensemble` 的温度、压力、弹性参数分别使用 K、GPa、GPa。温控和压控耦合输入表示 τ/Δt 的比值，而不是直接以 ps 填写。官方给出的约 100、1000 是参数选择参考，不能替代目标体系的验证。

若固定 Δt = 1 fs，输入比值 100、1000 分别对应 0.1 ps、1 ps。若改变 Δt，应说明保留的是物理弛豫时间还是输入比值。这是单位换算示例，不是某个合金的已验证设置。[C-01](../evidence/C-01-gpumd55.md)

`npt_ber` 与 `npt_scr` 的统计性质需要结合研究目标区分。使用体积涨落等统计量时，先核对算法是否适合；仅温压均值接近目标不能确认涨落分布正确。[M-02](../evidence/M-02-barostat.md)

## 盒子选择会施加额外约束

GPUMD 5.5 提供等比例缩放、正交方向分别控制和三斜盒控制等选项，并各有边界与盒型要求。[C-01](../evidence/C-01-gpumd55.md)

设计时先问候选结构变化是否需要长度比例改变或剪切，再选择允许的自由度。外压取零只是设定外部条件，瞬时压力仍会波动。应检查压力张量及盒子响应，而不只看一个末帧值。

## 用物理时间描述运行

固定步长时：`t = N_steps × Δt`。线性温度路径的速率为 `q = |T_end − T_start| / t_ramp`。有自适应步长或多阶段时，需按实际时间累计。

换算示例：`2×10^10 K/s = 20 K/ns = 0.02 K/ps`。这只是[P-02 文献速率](../evidence/P-02-paper-protocols.md)的单位转换；沿用它之前仍要匹配该研究的对象和目的。

## 第一版如何处理没有依据的数值

对已有论文参数，注明原任务与当前任务是否一致。资料不足时，可按 v0.2 决策规则提出完整的数值候选和判断标准，标明假设与预算；不要把候选或软件默认值升级为材料规律。真正影响研究定义的冲突才保留为待决策，未来参考值保留为运行时绑定。

明确区分三种完成状态：输入与短试跑通过、数值设置满足本次验证、研究结论得到所需证据。三者分别记录。
