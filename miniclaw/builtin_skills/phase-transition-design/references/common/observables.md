# 观测量怎样支持结论

[总目录](../index.md) · [当前能力](capabilities.md) · 依据：[M-01](../evidence/M-01-ptm.md)、[P-02](../evidence/P-02-paper-protocols.md)、[C-01](../evidence/C-01-gpumd55.md)

## 当前五类输出的含义

| 输出 | 直接描述什么 | 解释时需要补什么 |
| --- | --- | --- |
| PTM 原子比例 | 已开启结构模板与阈值下的局部环境分类 | 热扰动、缺陷、空间分布、化学有序与候选相关系 |
| 势能 | 保存数据中的势能及其每原子值 | 阶段、温度、成分和统计区间；它不包含动能 |
| 盒子体积 | 模拟盒子体积及每原子盒子体积 | 盒子形变、外压与真空；不能当作 Voronoi 原子体积 |
| 总 RDF | 原子对距离分布的径向统计 | 归一化、密度、帧平均/逐帧口径与元素加权 |
| 固定参考 MSD | 相对指定参考帧的平均平方位移 | 身份对应、PBC 展开、整体漂移、盒子仿射变化与采样区间 |

这些量可以互相补充。哪几项构成足够证据，应在研究设计时确定；增加图的数量本身不提高结论等级。

## 结构比例与相内成分

若分类 α 含 Nα 个原子、全体系有 N 个原子，则 `fα = Nα / N` 是该标签的原子比例。它并非直接测得的体积分数。

若还知道分类 α 中元素 e 的原子数 N(e,α)，则 `x(e|α) = N(e,α) / Nα` 是该分类内部的元素原子分数。只有先证明分类与物理相的对应关系，才能把它解释为相内成分。Nα = 0 时该量未定义，不能填成零来暗示不存在该元素。

当前工具没有这个联合统计功能，不能由 LLM 扫读长表补算。需要它时，应在方案中记录功能缺口及对结论的影响。[能力清单](capabilities.md)

## 化学有序需要独立指标

PTM 的几何结构和化学有序类型是不同输出。只查看 FCC/BCC 等比例，可能遗漏发生在相同晶格上的化学有序变化。OVITO 本身提供部分有序类型识别，但本项目当前工具只暴露了列明的局部结构比例。[M-01](../evidence/M-01-ptm.md)

## Other 的解释

Other 表示在当前模板与阈值下未被分类。液体、无序结构、缺陷和界面等都可能贡献该标签。应结合已选判据分析；不能直接把 Other 比例命名为液相分数。

## 玻璃转变与结构转变

玻璃转变研究需要保留热历史和时间尺度，并根据所选方法寻找相应变化。文献中的能量–温度判据见[P-02](../evidence/P-02-paper-protocols.md)。单温度平台的结构比例不能给出 Tg。

从温度扫描观察到的突变可先报告为本路径的转变信号或变化区间；进一步称为平衡相界，需要对应方法和证据。没有这些证据时保留条件限定。

## NPT 下的位移口径

盒子膨胀或收缩、质心漂移可能参与位移。报告 MSD 时说明是否去漂移、是否映射到参考盒子，以及固定参考帧。扣除仿射运动会改变所测量的量，不能只为了得到较小曲线而修改口径。

当前摘要中的均值是所选样本的等权均值。总 RDF 的所有 bin 均值、逐帧峰高均值和时间平均 RDF 是不同对象；使用时引用实际字段，避免互相替代。[当前工具口径](capabilities.md)
