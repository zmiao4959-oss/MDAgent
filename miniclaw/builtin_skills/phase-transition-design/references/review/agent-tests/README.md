# 研究 agent 行为评测

[知识库首页](../../README.md)

评测目标：agent 是否高效形成参数完整、单位一致、引用可追溯的研究方案。测试不运行 MD，也不证明材料精度、采样充分性或相变结论。

本目录保存迁移前 v0.1/v0.2 的原始评测记录；JSON、旧 manifests 与 ZIP 保留原始字节，其中的旧路径按[迁移指纹](../skill-migration.json)定位。以下行为和阅读成本结果不验证 v0.3 Skill 包装。迁移后的[16 例算术复核](../calculator-regression.json)及[CLI 检查](../calculator-cli-results.json)另存，只检查计算入口。

**最终结果：六类设计任务能交出完整候选参数包；原始数值检查、计算器和效率复测通过。来源标记中发现的错误已经修复并通过独立定向验收。原报告须连同修复覆盖层查看，不能把历史失败改写为首轮全对。**

## 基线

## 阅读效率复测

新的无历史 agent 重新从入口完成 N01、N02、G01，[原始紧凑回答](post-fast-route.json)保留公共控制复用。三题共读 5 份知识文件：N01/N02 各依赖 4 页，G01 又利用已读 UNEP 覆盖说明并读 Pd 包，共 5 页。Ti 的 10080 原子是“约一万原子”的明确新候选，不是把旧候选 9600 当硬事实；两种构造均需 model-worker 核实。

新紧凑回答的[43 项独立检查](fast-numeric-results.json)全部通过，涵盖数值、阶段总和、冷却时间、输出及登记引用。它仍曾使用混合来源容器，因此最终入口继续补上逐叶来源强规则，并形成[定向来源修复](post-fast-provenance.json)；不能把效率和数值通过当成原输出元数据全对。

## 独立审计与使用限制

独立 AI 审计检查数值、来源、候选边界和能力声明；它不替代材料专家的同行评审。当前未运行 MD、未测试 NEP 预测误差，也没有证明筛查阈值、系统尺寸、速率和时长已对具体材料收敛。若目标是精确 Tg、平衡相界、相内元素分配或加载下局部塑性，还要按能力缺口补方法与物理验证。

[第一轮修复验收](independent-remediation-audit.json)确认原审计的三类必要问题已修复，且保留当时尚未完成的快路由来源验收状态；后续补充单独保存，不倒改历史记录。

[最终独立验收](independent-final-gate.json)对原快路由报告加定向覆盖层给出 `PASS_FOR_ORIGINAL_PLUS_TARGETED_OVERLAY`。物理 tau/输入比值、初态候选/实际值、阶段与预算、执行状态轴及直接规则引用六项均通过，本次修复范围无未解决项。这是定向修复验收，不能计为十题再次盲测全通过。

测试 agent 可以提出 CAND 起点，但不能把它写成作者原协议、本次观测或普适最优参数。入口只负责高效产出可审阅设计。

## 算术检查

[固定算例](calculator-cases.json)与[CLI 结果](calculator-results.json)检查工程加载、独立初长、参考待绑定、温度路径、整数步取整、输出分辨率以及冲突/非法输入。计算器不替代参数选择，也不启动模拟。

复核入口：[check_calculator.py](../../../scripts/check_calculator.py)、[grade_agent_reports.py](../../../scripts/grade_agent_reports.py)。文档/资产完整性见[validation.json](../validation.json)，与行为测试分开。
